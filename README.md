# Maquina-de-refrescos


El archivo de bd usado esta en esta direccion
database\MaquinaRefrescos.sql


La cadena de conexión se encuentra en `src/MaquinaRefrescos.Web/appsettings.json`.

Para armar el proyecto:
dotnet run --project src/MaquinaRefrescos.Web

Para ejecutar las pruebas unitarias:
dotnet test MaquinaRefrescos.sln
